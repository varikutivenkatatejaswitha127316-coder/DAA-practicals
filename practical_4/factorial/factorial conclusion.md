 Iterative Factorial
 We successfully implemented the iterative factorial algorithm using a loop. It computes the result in \(O(n)\) time while maintaining an optimal \(O(1)\) space complexity, avoiding stack overflow issues for large inputs.

 Recursive Factorial
 We successfully implemented the recursive factorial algorithm where the function calls itself with decremented inputs. While clean and mathematically intuitive with \(O(n)\) time complexity, it requires \(O(n)\) auxiliary stack space due to recursive call frames.
