 Depth-First Search (DFS)
 We successfully implemented Depth-First Search (DFS) using recursion/stack to explore a graph as deeply as possible along each branch before backtracking. It runs in \(O(V + E)\) time and is widely used for cycle detection and topological sorting.

 Breadth-First Search (BFS)
 We successfully implemented Breadth-First Search (BFS) using a queue to explore a graph level by level. It executes in \(O(V + E)\) time and reliably finds the shortest path in unweighted graphs.
